# QuoteReady intake core 0.1.0-rc.1

An MIT-licensed, provider-independent evaluation preview for five-field service-request intake with transcript evidence, explicit unknown/declined states, detached review snapshots, and correction-aware approval.

This is a **GitHub prerelease**, not an npm registry publication, a stable API promise, a production voice-app deployment, or evidence of outside adoption. The larger maintenance PR #1 remains separate and unmerged. The release is approved for publication by the repository owner's request; review and tests are AI-assisted maintainer work, not independent human review or a Codex Security scan.

## Included

Installable `quoteready-intake-core-0.1.0-rc.1.tgz`, a credential-free evaluation guide (`QUICKSTART.md`), six clean-consumer runtime tests, consumer TypeScript checks, source/run provenance and SHA-256 checksums. The module has no runtime dependencies or installation scripts, and the MIT license is included in the archive. Node.js 22 and 24 are the tested release targets.

The executable core and declaration files are unchanged from source commit `75bf80912562b1cbe3982492dd516fc1b8aa2f3c`. Publication is gated on the full runtime suite on both Node targets, the existing offline Chromium suite, clean installation/import/behavior tests, declaration checks and exact package-file inspection. See `release-provenance.json` and the completed workflow jobs for actual outcomes; tests are not a security guarantee.

## Evaluation requested

Use the fixed fields in one bounded workflow and report whether it fits, what failed, and what you changed. Please distinguish trying the sample from integrating the component. No stars, endorsements or positive feedback are required. Real-speaker/audio performance and third-party deployment behavior are outside this core preview.

## Limits

Exact evidence matching is not semantic validation. Client-side approval is not authentication. The integrating application owns identity, authorization, consent, storage, safe rendering and consequential actions. Do not use the prototype for emergency or regulated decision-making. The package makes no bookings or network requests. The scan plan is a future proposal, not Security entitlement or certification.
